Campus Events Website
A simple and responsive college event website built using HTML, CSS, and JavaScript. Students can explore upcoming campus events, view registration fees, and open a registration form for the event they choose.
Features
- Home page with a welcome section
- Three sample events: Technical Fest, Cultural Fest, and Sports Day
- Event dates and registration fees
- Register Now buttons that open the registration form
- Form fields for student name and email
- Selected event and fee displayed automatically
- Confirmation message after submitting the form
- Styled layout with gradients, cards, hover effects, and a fade-in animation
Technologies Used
- HTML5 – page structure
- CSS3 – styling, layout, hover effects, and animation
- JavaScript – page navigation and registration-form interaction
How to Run
1. Download or clone this project.
2. Keep index.html in the project folder.
3. Open index.html in a web browser.
4. Select Register Now on an event, enter your details, and submit the form.

Note
This is a front-end demonstration project. The registration form displays a confirmation message in the browser; it does not save registrations to a database or send them to a server.
